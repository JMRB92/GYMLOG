GYM LOG v1.10

Publicación en GitHub Pages:
1. Haz una copia de seguridad desde Ajustes en tu versión actual.
2. Descomprime el ZIP y sube todo su contenido a la raíz del repositorio.
3. Conserva las carpetas data/, config/ y .github/.
4. Espera a que finalice GitHub Pages.

Prueba local:
- Abre el HTML independiente en Chrome.
- La biblioteca externa requiere conexión y puede no cargar con file:// por las restricciones del navegador. Para probarla completamente, sirve el contenido con un servidor local o usa GitHub Pages en un repositorio de prueba.

Datos y seguridad:
- La base `gymlog_db` existente se conserva y normaliza. Haz una copia de seguridad antes de actualizar.
- Las rutinas predefinidas están en data/routines.json. Las rutinas personales no se sobrescriben.
- GYM LOG PRO es un desbloqueo local, no un sistema de seguridad.
- Los vídeos se enlazan externamente; no se redistribuyen en este paquete.
