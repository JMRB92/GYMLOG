# Contribuir

1. Crea una rama para tu cambio.
2. Mantén la interfaz en español y adaptada a móvil.
3. No añadas analítica, anuncios ni envío remoto de datos personales sin una decisión explícita del proyecto.
4. Comprueba la sintaxis de JavaScript y prueba los flujos de crear/editar rutina, reanudar sesión, añadir/sustituir ejercicios y exportar/restaurar copias.
5. Describe los cambios y las pruebas realizadas en el pull request.
