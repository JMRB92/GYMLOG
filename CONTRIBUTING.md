# Contribuir a GYM LOG

1. Crea una rama para el cambio.
2. Mantén la aplicación ligera y sin dependencias externas salvo que sean necesarias.
3. No añadas telemetría, perfiles, cuentas, servicios remotos ni envío de datos personales sin documentarlo claramente y revisar sus implicaciones de privacidad.
4. Comprueba manualmente las funciones afectadas en escritorio y móvil.
5. Antes de enviar cambios, verifica la sintaxis de JavaScript y prueba crear, editar y borrar rutinas, registrar una sesión y exportar/restaurar una copia de seguridad.
6. Describe en el pull request qué cambió, cómo se probó y qué limitaciones quedan.
