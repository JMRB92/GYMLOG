# Seguridad y privacidad

GYM LOG guarda los datos en el almacenamiento local del navegador y no necesita credenciales. No incluyas archivos de copias de seguridad con datos personales en un repositorio público.

Si encuentras un problema, abre un issue sin publicar información privada ni copias de datos personales. Esta versión es un proyecto comunitario y no ofrece garantías de conservación de datos; mantén copias de seguridad independientes.
