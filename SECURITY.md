# Seguridad y privacidad

GYM LOG es una aplicación estática que guarda sus datos en el almacenamiento local del navegador. No introduzcas secretos, contraseñas ni información personal que no quieras conservar en ese dispositivo.

Si detectas una vulnerabilidad, evita publicar datos personales o copias de seguridad reales en un issue público. Abre un issue describiendo el problema sin datos sensibles o contacta de forma privada con el mantenedor del repositorio si has configurado un canal de contacto.

Las copias de seguridad exportadas pueden contener datos de entrenamiento; guárdalas como archivos privados y no las subas al repositorio.
